# 모델 스냅샷 (Model Snapshot)

API 모델 조합의 장단점을 채팅 중에 바로 기록하고 관리하는 실리태번 확장

## How to use

마법봉 메뉴 → **📸 지금 SHOT** 을 누르면 현재 설정이 통째로 카드로 만들어지며, 라벨을 붙이고 메모를 남겨 저장할 수 있습니다.

**카드 = 프로바이더 + 모델 + 후처리 + 프리셋명.** 이 네 가지가 같으면 같은 카드에 여러 샷이 쌓이고, 하나라도 다르면 새 카드가 생김. 파라미터(온도 등)도 기록되지만 분류 기준은 아닙니다.

프로바이더/모델에 커스텀 약칭을 붙여 저장할 수 있습니다.

## 기능

- **라벨** 
  - 기본 세팅 라벨: 검열 / 추론 / 품질(👍👎) / 이상증상 / 기술이슈 / 속도
  - 커스텀 추가 가능
- **검색·필터** — 약칭, 모델명, 메모, 캐릭터명, 라벨 등으로 검색 및 필터링
- **메시지 이동** — 샷 찍은 그 메시지로 이동하는 기능
- **비교** — 스냅샷 두 개의 설정 차이를 표로 비교
- **프로바이더 관리** — 가격 페이지 링크, 상태(정상/불안정/죽음), 엔드포인트 묶기
- **내보내기** — JSON(백업·복원), Markdown(정리용)

## 저장 방식

- 브라우저 **IndexedDB** 만 사용. ⚠️ **브- - 라우저 데이터를 지우면 기록도 사라짐.** 설정 탭에서 주기적으로 JSON을 내보내 백업. 리마인더 기능 On/Off 가능

- API 키와 프록시 비밀번호는 저장하지 않고 엔드포인트 URL은 저장되며 내보내기 파일에도 포함됩니다.


## 문제가 생기면

설정 탭 → 진단:
- **현재 캡처 테스트** — 어떤 항목이 안 읽히는지 확인
- **화면 배치 진단** — UI가 깨질 때
- **로그 보기** — 오류 기록
